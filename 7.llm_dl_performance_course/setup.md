# Course 7: Setup

## What You Need

### Required

- **Python 3.10+** — for any code examples or future labs.
- **Command line** — you should be comfortable from Course 1.
- **Web access** — to follow curated courses and videos (CS336, GPU MODE, NVIDIA, etc.).

### Optional (for hands-on later)

- **GPU with CUDA** — not required to complete the modules; useful if you run inference locally or replicate examples from the curated resources.
- **Cloud or lab GPU** — same as above; many concepts can be learned from slides and articles.

### Not required

- R (this course is Python- and resource-focused).
- Prior GPU or CUDA experience.

## Suggested order

1. Complete setup for Course 1 (Python, environment).
2. Skim `course_llm_dl_performance.md` and `START_HERE.md`.
3. Open `resources/reading/curated_readings.md` and bookmark the links you’ll use for Part 1.
4. Proceed through Part 1 modules, then Part 2.
